# ROBO剣 アーム制御 設計まとめ（目標位置ベース）

5軸アーム（根本 Yaw ＝ 精密サーボ ／ 残り4軸 ＝ QDD 電流制御ベースの位置制御）で相手の的を竹刀で打突する制御の設計方針と、振り中の高さリアルタイム補正の実装。低レベルは QDD の位置インタフェースを前提とする。

---

## 1. 基本方針

- QDD のルーズさは弾道的（ballistic）打突の **武器**。一点に剛く止める位置制御ではなく、的のサイズ許容内に **高速で通過** させる。
- 打突点は「終点」ではなく「終端速度を持って通過する via-point」。フォロースルーはその先に置く（打突点で止める軌道は失速する）。
- 長い竹刀のレバーで kinetic chain（proximal→distal の順次加速）を効かせ、可動域が小さくても先端速度と到達距離を稼ぐ。distal 側のスナップのタイミングが鍵。
- モーションは種別ごと（面・小手・胴）にプリセットを持ち、的位置に合わせて調整する。

---

## 2. 軸の役割分担（打突種別で変わる）

基本形：**Yaw（精密）＝方位、QDD 4軸 ＝ 打突平面内の振り**。5軸を「平面を向ける1軸 ＋ 平面内の4軸アーム」と見ると、IK が平面内 IK に落ちて素直になる。

精度が要る方向は打突種別で変わる：

| 打突 | 振り | 精度が要る方向 | 担当 |
|---|---|---|---|
| 面 | 縦落とし | 方位（azimuth） | 精密な Yaw（都合が良い） |
| 胴 | 横振り | **高さ** | 平面内の QDD 側（別戦略が要る） |

一般原則：「精密な軸に精度自由度を割り当てる」ではなく、**精度の要る方向と、速度を出す方向を、時間と向きで分離する**。

胴の場合：
- QDD チェーンが **高さを決めて保持**（精度担当）、**横の振りが速度** を出す。
- 横速度の出所は軸配置依存：純 pitch 列なら Yaw 掃引が主、手首に roll/yaw 軸があれば併用可。

---

## 3. 高さ精度を出す幾何（接触姿勢）

接触姿勢を、先端の velocity manipulability ellipsoid が **平たく** なる姿勢に選ぶ。

- **長軸 ＝ 打突方向**：小さい関節速度で高速に振れる。
- **短軸 ＝ 高さ方向**：低 manipulability なので
  - δq（関節角のばらつき）が先端高さにほとんど乗らない（受動精度 ↑）
  - タスク空間剛性 `K_x = J⁻ᵀ K_q J⁻¹` がその方向で大きい（外乱に硬い）

→ QDD がルーズでも「高さだけは」角度ばらつきに鈍感で外乱に強い姿勢が作れる。

実装は二相：
1. 低速 approach で高さを合わせ、平たい楕円の姿勢に入る
2. そこから保持しつつ横に高速で振る

---

## 4. 振り中の高さリアルタイム補正（目標位置ベース）

**IK は引き直さない。** プリセット `q_d(t)` に微分 IK の補正 `Δq` を足し、位置でサチュレートして `q_cmd` を渡す（closed-loop IK の累積形）。可動域を位置クランプで確実に防げるのが位置ベースの利点。

- 高さ Jacobian の行のみ `Jz`（`ż = Jz·q̇`）を使う。
- 目標高さ `z_target` は **必ずローパス / slew してから** 入れる（位置指令にステップが乗ると QDD 位置ループに巨大な過渡が出る）。

```text
# 振り始めで dq = 0 にリセット
# 毎制御周期:
q_d      = preset(t)                       # プリセット軌道
Jz       = height_jacobian_row(q)          # 1×n, ż = Jz·q̇  (Yaw列≈0 → pitch側に乗る)
ez       = z_target - fk_height(q_d + dq)  # 補正後リファレンスの高さ誤差
Jz_pinv  = Jzᵀ / (Jz·Jzᵀ + λ²)             # damped least squares（分母はスカラ）

dq      += k_clik * Jz_pinv * ez           # 高さを z_target へ（累積 ＝ 収束）
dq      += (I - Jz_pinv·Jz) · (-∇H(q))     # null空間: 高さ不変で姿勢をリミット中央へ
dq       = slew_limit(dq, dq_prev, dqdot_max*dt)  # レート/加速度制限（実現性）
q_cmd    = clamp(q_d + dq, q_min, q_max)   # 位置サチュレート（可動域）
# → QDD 位置ループへ

z_target = lowpass(z_target_raw)           # 目標高さは平滑化してから使う
```

`Jz·Jzᵀ` はスカラなので逆行列不要。1 kHz でも軽い。

**可動域・実現性の二段防御**
- `clamp()`：各関節のハードリミット（範囲を担保）
- `slew_limit()`：1周期で動かせる量（実現性を担保）

**律速はキネマティクスでなくダイナミクス**
高速運動の上に Δz を加速度として上乗せするので、効くかどうかは関節レンジより「残り時間で電流 / トルク飽和せずに Δz を出せるか」で決まる。接触直前が最難（速く、関節も端に寄る）。`slew_limit` の `dqdot_max` を **電流余裕から** 決めるのが実質の安全弁で、レンジ clamp より先に効く。届かないぶんは clamp で素直にニアミスを受ける。

**コンプライアンス保持**
純位置追従で剛にしすぎると運動量と喧嘩して接触が硬くなる。QDD 位置ループの内側が電流モードなら、`Kp` を上げすぎず、重力 / 慣性の feedforward を入れ、接触付近では剛性を落とす。

**受動精度 vs 能動補正のトレードオフ（§3 と接続）**
`Jz_pinv` のゲインは実質 `1/‖Jz‖²`。高さを短軸（低 manipulability）に置くと受動精度は上がるが、`‖Jz‖²` が小さい ＝ Δz を出すのに大きい Δq が要る ＝ リミットに当たりやすい（能動補正は高コスト）。
→ リアルタイム補正を効かせたいなら、`λ` と `‖Jz‖` を監視しつつ「ジッタには鈍いが、小さい Δz なら関節 headroom 内で出せる」σ に姿勢を寄せる。

**早期検出の原則**
検出が早いほど 1 ステップの Δq は小さく、関節 travel も残り、必要な q̈ も小さい。可能な限り早く補正を始める。
